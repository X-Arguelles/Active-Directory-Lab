# Active-Directory-Lab
<h2>Description:</h2>
This project is a walkthrough of how I set up an Active Directory Home Lab using Hyper-V. I set up a Windows Server to run Active Directory on it and configured a Domain Controller to run a domain and a user.

<h2> Utilities & Software Used:</h2>
- Hyper-V
- Active Directory
- Windows Server 2025
- Windows Pro Workstation
